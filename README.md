# SDG 3: Drivers of Life Expectancy Across Countries

Juliana Paula T. Binas | BSIS 3A | Analytics Techniques and Tools

Multiple linear regression (OLS) and robust regression (Huber RLM) on standardized variables, with an interactive Streamlit dashboard.

| File | Purpose |
|---|---|
| app.py | Streamlit dashboard (main file) |
| SDG3_Life_Expectancy_Regression.ipynb | Regression analysis notebook |
| merged_sdg_data.csv | Dataset (World Bank, Our World in Data; UK and US, 2000-2024) |
| requirements.txt | Python packages for deployment |
| .streamlit/config.toml | Light theme settings |

Run locally:

    pip install -r requirements.txt
    streamlit run app.py
